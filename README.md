# Vanilla JS TODO App

外部ライブラリ（ReactやVueなど）を使用せず、素のJavaScript（Vanilla JS）のみで構築したタスク管理アプリケーションです。
フロントエンドの基礎的なデータの流れやDOM操作を深く理解することを目的として作成しました。

## デモ
 [https://tak943.github.io/Todo-app/]

## 工夫した点・学習目的
- FWに頼らないDOM操作: イベントリスナーを用いた要素の追加・削除・状態変更を1から実装。
- モジュール化を意識した設計: メンテナンス性を考慮し、機能ごとに関数を複数ファイルに分割して管理。
- コードリーディングと構造理解: デベロッパーツールを用いて変数の推移を追跡し、手本の技術書のコードを読みといて学習しました。
- （予定）データの永続化: 今後、localStorageを用いたデータ保存機能を追加予定。
